## 🚀 Software Engineer • Algiers, Algeria

I build products **end to end**: mobile apps used by thousands of people, the **backends** behind them, and the **pipelines** that ship them.
Most of my work is in **Flutter**, with **FastAPI**, **Supabase** and **PostgreSQL** on the server side and **GitHub Actions** and **Fastlane** for releases. I care about clean architecture, reliable networking, and shipping fast without breaking things.
